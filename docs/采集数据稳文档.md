## 详细说明   只看第一个

### 1. 精密装配任务数据（Task_Data/）

任务名均为 `precision_assembly_ab_v1`，采集平台为遥操作系统，每条 episode 为一个独立目录，命名格式：

```
<时间戳>_precision_assembly_ab_v1-unassigned-episode-<编号>_<哈希>
```

单条 episode 内部结构：

```
episode-xxx/
├── artifacts/          # rosbag2 数据包、采集清单、校验文件
├── config/             # 采集配置
├── context.json        # 采集环境信息（系统、内核、Python 版本等）
├── logs/               # 日志
├── result/             # 结果
└── run.json            # 运行记录
```

- **Task_Data1**（61G）：2026-08-09 ~ 08-31 采集。101 条精密装配 episode（episode-1 ~ episode-15，每个编号多次重复采集），另有 3 条 teleop-episode、2 条 camera-angle-capture（相机角度标定）及时间同步报告等附属文件。
- **Task2_Data**（11G）：2026-09-04 采集。52 条精密装配 episode（episode-1 ~ episode-30，部分编号有 2 次采集），含 manifest.json。
- **task3_Data**（25G）：2026-09-05 采集。100 条精密装配 episode（episode-1 ~ episode-50，前期编号多有 3 次采集）。
- **ICRA2027/task3_Data**（25G）：与 `Task_Data/task3_Data` 目录列表完全相同，为同一份数据的备份。
