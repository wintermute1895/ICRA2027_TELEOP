## LinkerTA V2 快速上手指南


### 一、描述
* LinkerTA 是由灵心巧手（北京）科技有限公司开发，用于第二版遥操臂的驱动程序。 

### 二、环境要求
* 系统版本：Ubuntu 20.04以上
* ROS版本：ROS2

### 三、启动CAN设备
sudo ip link set can0 up type can bitrate 1000000


### 四、相关说明
1. 核心参数配置
    文件路径：linkerta_v2/src/linkerat/config/lta.yaml

	| 序号 | 参数        | 说明                                                 |
	| :--- | :---------- | :------------------------------------------------- |
	| 1    | calibration | 对所有关节进行标定（0关闭标定 1开启标定）                |

2. 遥操臂标定
	| 序号 | 说明                 |
	| :--- | :----------------------- |
	| 1    | 将每个遥操臂关节转动到刻度线 |
	| 2    | 将参数配置中的 calibration 改为 1，编译|
	| 3    | 运行 run.launch.py 文件 完成标定 |
	| 4    | 将参数配置中的 calibration 改为 0，编译 |

4. 数据输出
    终端打印：ros2 topic echo 话题名称

	| 序号 | 话题名称                 | 说明                         |
	| :--- | :----------------------- | :------------------------ |
	| 1    | /left_arm_joint_control  | 左臂关节位置数据             |
	| 2    | /right_arm_joint_control | 右臂关节位置数据             |
	| 3    | /joint_error_code        | 所有关节状态 1：故障  0：正常 |
